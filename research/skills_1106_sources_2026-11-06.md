## vr-anticheat-plausibility (new)
- Our design + measurements **[measured]**: netsafe_1106 / netsafe2_1106 (M5 pose reach clip + travel budget with bank, M6 server-side throw cap + ballistic cone, M10 protocol hash over 21 scripts / 169 RPCs, export parity `same hash`; mp/netsafe 9/0, mp/netsafe_giant 5/0; the 20-suite false-positive sweep: Spleef round placements and lagging bot hands found), telesafe_1106 (one `Teleport` API, grants/registry/rescue trail, the lint guard with 31 pinned markers + a planted-violation control, lifts converted to server-authoritative rides with zero log lines, mp/teleports 9/0).
- Gabriel Gambetta, "Fast-Paced Multiplayer (Part I): Client-Server Game Architecture" — the server as "the one and only authority"; don't trust the player **[secondary]** (fetched 11-06).
- Epic Games, "Remote Procedure Calls in Unreal Engine": `WithValidation` / `_Validate` runs on the server first; a failed validation disconnects the caller ("trust and verify") **[doc]** (via search summary).
- Unreal `UCharacterMovementComponent` / `AGameNetworkManager`: server move checks + `ClientAdjustPosition` corrections; movement time-discrepancy detection (off by default) **[doc]** (via search summaries; not used numerically).
- Photon Fusion 2 docs + the Fusion Godot topology guide: cheat protection is strong with a dedicated server's state authority, weak in host/shared modes; "I suggest input, the authority decides" **[doc]** (via search summaries).
- Valve Developer Community, "Lag Compensation": the server rewinds player positions; `sv_maxunlag` default/max 1 s of history (CS:GO/CS2 use 0.2 s per third-party command references) **[doc]** (search summary; the page itself returned 403 to the fetcher).
- Godot docs, "High-level multiplayer": validate RPC arguments; `get_remote_sender_id()`; `any_peer` vs `authority`; RPCs must be declared on both ends at the same node path, but "Function arguments are not checked for matching" **[doc]** (fetched 11-06). `allow_object_decoding` from the `SceneMultiplayer` class reference **[doc]**.
- SpatialOS VR starter project (server checks that hand and object collide before accepting a grab) and "Never trust the client" (Game Developer) **[secondary]**: the same server-validates-grab/move pattern; background only.
- Free fall from 828 m without drag = √(2·9.81·828) ≈ 127 m/s (arithmetic).
